# RecipeServ

Серверная часть приложения для работы с рецептами. Реализует регистрацию и авторизацию пользователей, управление рецептами и ингредиентами, добавление оценок, работу с аватарами и фотографиями. Сервер взаимодействует с базой данных и предоставляет API для клиентского приложения.
